# 이번 주 자유수영 안내

[홈페이지](https://jaystarboard.github.io/swim-info/)는 안양·의왕·성남·수원
7개 시설의 이번 주 일요일과 공휴일·대체공휴일 자유수영 정보를 보여줍니다.
운영 시간, 휴장, 확인 필요 상태와 마지막 갱신 시각을 표시합니다. 토요일은
파란색, 일요일·공휴일은 빨간색, 휴장 시설은 회색 배경으로 구분합니다.

이 저장소는 **공개 페이지의 결과물**만 보관합니다. 정보 수집·분석과 카카오톡
발송은 비공개 [`kakao-daily-english`](https://github.com/jaystarboard/kakao-daily-english)
저장소의 `swim-weekly.yml`에서 실행됩니다. 월요일 한국시간 07:00을 목표로
06:50에 시작하고 07:10·07:30에 재확인하며, 같은 주의 중복 메시지는 방지합니다.
워크플로가 성공하면 이 저장소의 `index.html`이 자동 갱신됩니다.

자동화가 실패하면 페이지에는 **마지막으로 성공한 결과가 그대로 남습니다**.
따라서 방문 시 상단의 갱신 시각과 안내 대상 날짜를 확인하고, 출발 전에는
시설의 공식 공지도 다시 확인하세요. 이 저장소의 HTML을 직접 수정해도
다음 자동 갱신에서 덮어써질 수 있습니다. 수정은 원본 자동화 저장소에서
진행해야 합니다.
